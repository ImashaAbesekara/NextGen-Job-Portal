# NextGen AI-Powered Job Portal System

A dynamic recruitment platform built with the MERN stack featuring AI-driven tools for job seekers and recruiters.

## 🚀 Key Features
- **Multi-Role Dashboards:** Distinct workflows for Job Seekers, Employers, and Admins.
- **AI Integration:** Automated cover letter generation and optimized job description tools using Generative AI APIs.
- **Security:** Secure RESTful APIs with JWT authentication and Role-Based Access Control (RBAC).

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **AI Services:** Generative AI Microservices

## 📂 Project Structure
- `job-portal-frontend/`: Client-side React application
- `job-portal-backend/`: Node.js & Express API server
